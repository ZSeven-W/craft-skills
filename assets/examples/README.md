# Visual examples

Most artwork in this directory was created specifically for fictional teaching and regression cases in this repository. The rights-reserved Tuanzi and Hutao exception is identified below. Nothing here reproduces or traces any logo, frame, thumbnail, screenshot, or other visual asset from the linked research videos.

- `handoff/` is the primary hero case: six original concept families, a selected `Relay Joint H`, a responsive micro mark, and a rendered QA board.
- `xiuyue/` is a script-safety case: the symbol combines a page contour with mountain shoulders while keeping the Chinese wordmark unmodified.
- `d-tool/` is a regression fixture: it demonstrates an iteration after a small-size failure and must not be presented as a hero identity or distinctiveness claim.
- `recurring-character-diary-comic/` is the generated-original comic hero: a fictional two-character episode composed with irregular panels and deterministic Simplified Chinese lettering. The public cover is a reduced review render; it does not include internal profiles, prompts, run records, or source panels.
- `native-transparent-imagegen/` contains Fini Yang's watermarked first-version Tuanzi and Hutao character action sheet, included by explicit permission as the public fur-edge case. It is rights-reserved and is not licensed under Apache-2.0.

The SVG files are editable source artifacts. The PNG files are fixed review renders or native-size regression outputs. Approved public assets are hash-pinned by `scripts/check_release.py`; changing an asset requires an intentional checksum update and visual review.

Except for the rights-reserved Tuanzi and Hutao case above, these original project assets are covered by the repository's Apache-2.0 license. Names and marks are fictional teaching devices and are not trademark clearance.
